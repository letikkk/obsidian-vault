## 🤖 AI Agent Integration
This vault is configured for direct AI agent integration:
- **Central Guidelines:** See [[AI-Guidelines]] for rules on how agents interact with your notes.
- **Agent Scratchpads:** Use `Templates/AI Agent Scratchpad Template` for complex agent planning.
- **Attachments:** All screenshots and media automatically go to `Assets/` to keep your root directory clean.

## 🛠️ Helpful Shortcuts in Obsidian
- `Ctrl + O`: Quick Switcher (find and open any note).
- `Ctrl + P`: Command Palette (access any Obsidian command).
- `[[`: Type two open brackets to link to any note.
- `Ctrl + Click`: Open linked note in a new tab.
