## 🧩 Installed Community Plugins & Highlights

| Plugin | What It Does & How to Use |
| :--- | :--- |
| **Dataview** | Dynamic querying for notes, tables, and lists via markdown blocks (` ```dataview `). |
| **Tasks** | Checkbox query engine (` ```tasks `), recurring tasks, and due dates. |
| **Kanban** | Trello-style boards directly inside markdown (see [[01 - Projects/Project Kanban\|Project Kanban]]). |
| **Templater** | Dynamic templates with prompt insertion and date logic (`Alt + E` or Command Palette). |
| **Calendar** | Visual monthly calendar in the right sidebar linking directly to daily notes. |
| **Advanced Tables** | Press `Tab` and `Enter` inside markdown tables to automatically format columns. |
| **Omnisearch** | High-speed fuzzy search across all notes, PDFs, and OCR text (`Ctrl + Shift + F` or palette). |
| **QuickAdd** | Rapid capture hotkeys for dumping thoughts into notes without changing context. |
| **Linter** | Auto-formats Markdown, headings, lists, and YAML metadata upon saving. |
| **Iconize** | Right-click any folder or note in the left file tree to assign icons. |
| **Minimal Theme & Settings** | Clean aesthetics designed by Steph Ango. Customize fonts and accents in Settings. |
| **Local REST API** | Secure local API server for external AI agents (Claude Code, Antigravity, Python scripts). |
